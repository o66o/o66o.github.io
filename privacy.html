JobHunter: Privacy Policy

Last updated: 25 September 2026

JobHunter is a personal tool used only by its owner, Yuri Gorskiy. It is not available to the public.

Data accessed

With the owner's consent, JobHunter uses the Gmail API with the read-only scope (gmail.readonly) to read job-alert emails in the owner's own mailbox and extract links to job postings.

Use, storage and sharing

Extracted data is stored only on the owner's computer and used only for the owner's job search. It is not sold, shared with third parties, or used for advertising. JobHunter never sends, modifies or deletes email.

JobHunter's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
